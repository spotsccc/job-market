# Моки экранов v1

Исходники моков интерфейса к [пользовательскому флоу](../01-user-flow.md). Данные в них выдуманные (компании, вакансии, цифры), но согласованы между экранами.

| Файл | Экран |
|---|---|
| `Main.dc.html` | Онбординг, шаг 1 — о себе |
| `Plan.dc.html` | Онбординг, шаг 2 — где искать и какие запросы будут выполняться |
| `Progress.dc.html` | Онбординг, шаг 3 — первый сбор |
| `Inbox.dc.html` | Inbox — основной экран |
| `Search.dc.html` | База — поиск по всем собранным вакансиям |
| `Profile.dc.html` | Профиль и план поиска |
| `canvas.json` | раскладка экранов на холсте и стикеры «что оценить» |

Формат файлов — Design Component (`.dc.html`) холста Claude: разметка + небольшой класс с логикой. Отдельно в браузере они не открываются — им нужен рантайм холста (`support.js`). Живая версия с кликабельными экранами: https://claude.ai/artifact/JDuPyduFFQU5f5HHP1nC7Z (приватная, доступ — через Share).
